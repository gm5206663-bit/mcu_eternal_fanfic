# NO-MISTAKE LIVE RULES — MCU Eternal OC (v1)

**If any rule conflicts with a cool scene, the rule wins. Rewrite the scene.**

## Twin law (v2.0 §61)
### Never nerf (without explicit cause)
- Never forget his 7000 years (languages, Deviant patterns, team combos, rescue calm).
- Never make ordinary Deviants hard again after mastery (unless new biology/numbers/hostages — name the new variable).
- Never write restraint as weakness: holding back for civilians = VISIBLE (feathered field edge, softened landing, apologetic glance to Makkari). State "he held back" through ACTION, not narration excuses.
- Never collapse his parallelism: he can anchor + sense + catch + shout warnings SIMULTANEOUSLY (veteran). Don't reduce him to one action per beat to save canon.
- Never invent fatigue/overload/fear to preserve canon. Overload needs TRACEABLE cause (buffer-full + crush-zone + anchor + wound TOGETHER, not one punch).
- Never make him passive/late/blind to let Kro/Ikaris succeed. If he's there with working senses, he ACTS. If you need him absent, move him EARLIER with a real errand (Ajak's orders, rescue, Domo duty).

### Never inflate (without earned cause)
- No new powers from one exposure. Kro drain = WOUND + INFORMATION, not kinetic-drain immunity.
- No technique counted as new ability (Slingshot Counter = gravity+kinetic combo, NOT a third power).
- No mastery from first success (first Uni-Mind = clumsy, first Tiamut stand = kneeling).
- No numbers/percentages/ranks without source (MCU has no power levels — use FEATS + CONDITIONS + COSTS).
- No borrowed authority as ownership (Uni-Mind boost FADES after link breaks).
- No free Celestial defiance (Arishem gaze = kneel + endure, NOT stand + speech at entry).

## Canon guards
- True mission reveal ONLY via Ajak→Ikaris→team canon chain. OC deduces NOTHING before evidence (dreams ≠ proof).
- Gilgamesh fate follows locked branch option (A/B/C) once chosen. No silent flip.
- Sersi remains transmutation + Uni-Mind center. OC feeds, anchors, protects — never replaces — unless you approve.
- Snap/Blip/Avengers history UNTOUCHED. Eternals observed, never intervened.
- No Soul Land leakage (rings, souls, cultivation). No comics-only powers (molecule-control True Eternal stuff) unless you approve a specific ascension arc.

## Talent portrayal (v2.0 §63)
- FORBIDDEN in prose: "the Talent spoke/decided/wanted/calculated/scanned/issued a warning/opened a menu." No percentages, no lab monologue.
- REQUIRED: breath, stance, grip, timing, recovery, hunger-analog (stillness need), gold-mote bleed, field flicker, instinctive brace, changed rhythm. Let the ENEMY notice ("he was already moving before I lunged").
- Name "Adaptation Talent" NEVER in-story. In-world characters say "oddly deep," "old hands," "Kro's hunger," "Phastos's drift." Only reference docs use the true name.

## Power guards (from POWER_LAW)
- Buffer ceiling HARD. Gravity radius/duration HARD. Energy≠kinetic (cannot absorb beams). Contact-only kinetic. Concentration-required fields.
- State every big feat as: state (unassisted/assisted/charged/combo/amped/overdrive) + cost + what REMAINS outside scope.

## Continuity
- Panel wins over prose. Update panel delta after every chapter. Log butterflies in codex/BUTTERFLY_EFFECTS.md with CAUSE → CHANGE → PERMANENT CONSEQUENCE.
- Time gaps = growth (training, grief, team reactions, institution moves). Never "nothing happened."
- Institutions remember: post-Tiamut world (governments, media, Avengers-adjacent) reacts to a marble Celestial + 11 Eternals. Cannot pretend nothing happened.

## Pre-delivery audit (silent, before every chapter/panel)
1. Latest checkpoint? Age/location/wounds/buffer/equipment/bonds correct?
2. Canon cause still present? Butterfly honored? Anyone nerfed to save canon?
3. Adaptation: foundation? new input? pathway? cost? power vs technique? confirmed/developing? first exposure dangerous? known threat easier? overload causal?
4. Talent non-sentient? Embodied? Emotions/flaws/culture real? Everyone acts on THEIR knowledge only?
5. Full capacity used? Restraint visible? Costs real? No auto-scaled villains?
6. World remembers? Knowledge firewalls respected? Geography + response time honest?
Fail any → revise before delivery.
